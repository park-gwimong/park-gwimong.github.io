고르게 하는 것 7가지

선택을 받는 컴포넌트는 하나만 고르는지 여러 개를 고르는지에서 먼저 갈립니다. 고른 것이 언제 적용되는지, 선택지가 몇 개인지를 나란히 놓고 봅니다.
