버튼의 종류와 위계 7가지

버튼의 모양은 그 화면에서 무엇이 먼저인지를 알리는 신호입니다. 한 화면 안에서의 우선순위와, 동작인지 이동인지를 나란히 놓고 봅니다.

칸을 누르면 그 예시가 다시 재생됩니다.

  • 취소저장

    01주 버튼

    Primary button

    그 화면에서 가장 중요한 동작 하나에 쓴다.

    위계: 높음동작 · 화면에 하나

  • 장바구니바로 구매

    02보조 버튼

    Secondary button

    주 버튼 옆에서 취소나 대안처럼 그보다 덜 중요한 동작에 쓴다.

    위계: 중간동작 · 주 버튼 옆

  • 알림을 켤까요? 새 댓글을 바로 알려 드려요
    나중에켜기

    03텍스트 버튼

    Text button

    눈에 덜 띄어도 되는 동작에 쓰고, 한 화면에 여러 개 있어도 된다.

    위계: 낮음동작 · 여러 개 가능

  • 공유

    04아이콘 버튼

    Icon button

    자리가 좁고 뜻이 널리 알려진 동작을 아이콘만으로 보여 준다.

    위계: 낮음동작 · 이름 필요

  • 05플로팅 액션 버튼

    Floating action button · FAB

    화면의 대표 동작 하나를 내용 위에 띄워 스크롤해도 같은 자리에 있게 한다.

    위계: 가장 높음동작 · 떠 있음

  • 계정 삭제 모든 데이터가 지워집니다 계정 삭제

    06위험 버튼

    Destructive button

    삭제나 탈퇴처럼 되돌리기 어려운 동작임을 누르기 전에 색과 글자로 알린다.

    위계: 따로 구분동작 · 되돌리기 어려움

  • 결제일은 매달 1일입니다.자세한 내용은 요금 안내에서확인할 수 있습니다.

    example.com/pricing

    07링크

    Link

    무언가를 실행하는 것이 아니라 다른 페이지나 위치로 옮겨 갈 때 쓴다.

    위계: 본문 수준이동 · 주소가 바뀜

비교표와 고르는 기준은 블로그 글에 있습니다.
