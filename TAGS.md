# Tag Guidelines

Use tags to help search and grouping across the blog. Keep them consistent and reusable.

## Format

- Use Title Case or accepted product casing (e.g., `GitLab CI/CD`, `PlantUML`, `C#`, `C++`).
- Use uppercase for acronyms (e.g., `HTTP`, `DNS`, `SQL`).
- Prefer spaces over hyphens unless the official name uses a symbol (e.g., `C#`, `C4 Model`).
- Keep tags short (1-3 words) and ASCII only.
- Prefer singular nouns (e.g., `Transaction`, not `Transactions`).

## Placement

Put tags in front matter as an inline list, ideally right after `category`:

```yaml
---
title: "..."
category: "..."
tags: ["Tag A", "Tag B"]
---
```

## Selection

- Use 2-5 tags per post.
- Order tags from broad to specific.
- Reuse existing tags whenever possible.
- Add a new tag only when it adds a distinct, reusable concept.
