설정 화면을 만들다 보면 "이건 체크박스인가 스위치인가"에서 자주 멈춘다. 선택을 받는다는 점은 같지만 몇 개를 고르는지와 언제 적용되는지가 다르다.

이 글은 헷갈릴 때 꺼내 보려고 만든 참고서의 셋째 장이다. 일곱 가지를 나란히 놓고, 하나만 고르는지와 고른 것이 언제 적용되는지, 선택지가 몇 개인지를 기준으로 구분한다.

## 한눈에 비교

| 이름 | 고르는 수 | 적용되는 때 | 선택지 수 | 쓰는 때 |
| --- | --- | --- | --- | --- |
| 체크박스 (Checkbox) | 여러 개 | 제출할 때 | 적은 편 | 서로 상관없는 항목을 원하는 만큼 고를 때 |
| 라디오 (Radio button) | 하나 | 제출할 때 | 둘에서 다섯쯤 | 선택지를 모두 펼쳐 놓고 하나를 고를 때 |
| 스위치 (Switch, Toggle) | 켬과 끔 | 즉시 | 설정 하나 | 설정 하나를 바로 켜고 끌 때 |
| 세그먼트 컨트롤 (Segmented control) | 하나 | 즉시 | 둘에서 다섯쯤 | 같은 내용을 보는 방식을 바꿀 때 |
| 칩 (Chip, Filter chip) | 보통 여러 개 | 즉시 | 여러 개 | 목록을 조건으로 바로 거를 때 |
| 셀렉트 (Select, Dropdown) | 하나 | 폼이면 제출할 때 | 많음 | 선택지가 많아 접어 두어야 할 때 |
| 콤보박스 (Combobox, Autocomplete) | 하나 | 폼이면 제출할 때 | 아주 많음 | 입력해서 걸러 낸 뒤 고를 때 |

표는 가장 흔한 쓰임을 기준으로 적었다. 체크박스 하나만 두어 동의 여부를 받는 경우도 있고, 셀렉트와 콤보박스에도 여러 개를 고르는 형태가 있다.

칩과 콤보박스는 뜻이 넓은 말이다. 칩에는 입력한 값을 나타내는 칩이나 동작을 제안하는 칩도 있는데, 여기서는 켜고 끄는 필터 칩을 가리킨다. 콤보박스는 WAI-ARIA에서 목록을 여는 입력 전반을 이르는 말이고 입력 없이 고르기만 하는 형태도 포함한다. 여기서는 글자를 입력해 선택지를 걸러 내는 형태를 가리킨다.

## 고르는 기준

위에서부터 차례로 묻고, 처음 "예"가 나오는 것을 고른다.

1. **설정 하나를 켜고 끄며, 누르는 즉시 적용되는가.** 그렇다면 스위치다. 저장 버튼을 눌러야 적용된다면 체크박스 하나를 쓴다.
2. **여러 개를 고를 수 있는가.** 폼에 담아 제출하는 값이면 체크박스다. 목록을 바로 거르는 조건이면 칩이다.
3. **하나만 고르고, 선택지가 다섯 개쯤을 넘지 않는가.** 보는 방식을 바로 바꾸는 것이면 세그먼트 컨트롤이다. 폼에 담는 값이면 라디오다.
4. **하나만 고르고, 선택지가 그보다 많은가.** 그렇다면 셀렉트다.
5. **선택지가 훑어서 찾기 어려울 만큼 많은가.** 그렇다면 콤보박스다. 나라, 도시, 사람 이름이 여기에 든다.

선택지는 펼쳐 둘 수 있으면 펼쳐 둔다. 라디오와 세그먼트 컨트롤은 누르지 않아도 무엇을 고를 수 있는지 보이지만, 셀렉트와 콤보박스는 열어 봐야 보인다.

## 자주 틀리는 것

- **저장 버튼이 있는 폼에 스위치를 쓴다.** 스위치는 누르는 순간 적용된다는 약속을 담은 모양이다. 저장을 눌러야 반영되는 폼에 넣으면 사용자는 이미 적용됐다고 믿고 화면을 떠난다. 제출할 때 적용되는 값은 체크박스로 받는다.
- **하나만 고를 수 있는데 체크박스 모양으로 그린다.** 네모는 여러 개, 동그라미는 하나라는 규칙을 사용자는 모양으로 읽는다. 모양과 동작이 어긋나면 고른 것이 왜 풀렸는지 알 수 없다. 하나만 고르면 라디오, 여러 개면 체크박스로 맞춘다.
- **선택지가 두세 개뿐인데 셀렉트에 넣는다.** 열어 보기 전에는 무엇이 있는지 알 수 없고, 고르는 데 누르는 횟수도 늘어난다. 펼쳐 둘 자리가 있으면 라디오나 세그먼트 컨트롤을 쓴다.
- **고르지 않아도 되는 항목을 라디오로 받으면서 "선택 안 함"을 두지 않는다.** 라디오는 한 번 고르면 다른 것으로 옮길 수만 있고 비울 수는 없다. 고르지 않는 것도 답이라면 그 선택지를 하나 더 둔다.
- **선택지가 수십 개인데 셀렉트로 둔다.** 긴 목록을 스크롤해서 찾아야 하고, 모바일에서는 더 힘들다. 입력해서 걸러 낼 수 있는 콤보박스로 바꾼다.

## 정리

- 먼저 하나를 고르는지 여러 개를 고르는지 묻는다. 여러 개면 체크박스나 칩이고, 하나면 나머지 가운데서 고른다.
- 누르는 즉시 적용되는지가 모양을 가른다. 즉시 적용되면 스위치, 세그먼트 컨트롤, 칩이고 제출할 때 적용되면 체크박스와 라디오다.
- 선택지가 적으면 펼쳐 두고, 많으면 접고, 아주 많으면 입력해서 거르게 한다.

> 고르는 컴포넌트의 모양은 몇 개를 고를 수 있고 언제 적용되는지를 미리 알려 주는 약속이다.
