한 화면에 버튼이 셋 있는데 셋 다 같은 색으로 채워져 있으면 어느 것도 먼저 눈에 들어오지 않는다. 버튼의 모양은 꾸밈이 아니라 무엇이 먼저인지를 알리는 신호다.

이 글은 헷갈릴 때 꺼내 보려고 만든 참고서의 열 번째 장이다. 버튼 여섯 가지와 링크를 나란히 놓고, 한 화면 안에서의 우선순위와 동작인지 이동인지를 기준으로 구분한다.

## 한눈에 비교

| 이름 | 위계 | 동작인가 이동인가 | 쓰는 때 |
| --- | --- | --- | --- |
| 주 버튼 (Primary button) | 높음 | 동작 | 화면에서 가장 중요한 동작 하나 |
| 보조 버튼 (Secondary button) | 중간 | 동작 | 주 버튼 옆의 취소나 대안 |
| 텍스트 버튼 (Text button) | 낮음 | 동작 | 덜 띄어도 되는 동작, 여러 개가 나란히 놓일 때 |
| 아이콘 버튼 (Icon button) | 낮음 | 동작 | 좁은 자리에 놓는 널리 알려진 동작 |
| 플로팅 액션 버튼 (Floating action button, FAB) | 가장 높음 | 동작 | 스크롤해도 같은 자리에 있어야 하는 대표 동작 |
| 위험 버튼 (Destructive button) | 따로 구분 | 동작 | 삭제나 탈퇴처럼 되돌리기 어려운 동작 |
| 링크 (Link) | 본문 수준 | 이동 | 다른 페이지나 위치로 가기 |

이름은 디자인 시스템마다 다르다. 텍스트 버튼은 3차 버튼(tertiary)이나 플랫 버튼으로도 불린다. 고스트 버튼이라는 말은 시스템에 따라 테두리만 있는 버튼을 가리키기도 하고 글자만 있는 버튼을 가리키기도 하므로, 팀 안에서 뜻을 정해 두고 쓴다.

플로팅 액션 버튼은 머티리얼 디자인에서 온 패턴이다. 애플의 가이드라인에는 같은 이름의 컴포넌트가 없으므로, 플랫폼의 관례를 따르는 화면이라면 쓰기 전에 한 번 더 따져 본다.

## 고르는 기준

위에서부터 차례로 묻고, 처음 "예"가 나오는 것을 고른다.

1. **누르면 다른 페이지나 위치로 가는가.** 그렇다면 링크다. 모양을 버튼처럼 그리더라도 요소는 링크로 만든다.
2. **되돌리기 어려운 동작인가.** 그렇다면 위험 버튼이다.
3. **그 화면에서 가장 중요한 동작인가.** 그렇다면 주 버튼이다. 긴 목록 위에서 늘 보여야 하는 대표 동작이면 플로팅 액션 버튼을 쓸 수 있다.
4. **주 버튼 곁에 놓이는 대안인가.** 그렇다면 보조 버튼이다.
5. **자리가 좁고 아이콘만으로 뜻이 통하는가.** 그렇다면 아이콘 버튼이다.
6. **나머지는 텍스트 버튼이다.**

위계는 버튼 하나의 성질이 아니라 한 화면 안에서의 상대적인 순서다. 주 버튼이 눈에 띄는 것은 나머지가 덜 띄게 그려졌기 때문이다.

## 자주 틀리는 것

- **한 화면에 주 버튼을 여러 개 둔다.** 전부 강조하면 아무것도 강조되지 않는다. 가장 중요한 동작 하나만 채워 그리고 나머지는 보조 버튼이나 텍스트 버튼으로 내린다.
- **이동을 버튼으로, 동작을 링크로 만든다.** 링크는 새 탭으로 열거나 주소를 복사할 수 있고, 스크린 리더가 링크라고 읽어 준다. 키보드로 누르는 법도 다르다. 링크는 Enter로, 버튼은 Enter와 Space로 실행된다. 주소가 바뀌면 `<a>`, 그 자리에서 무언가를 실행하면 `<button>`을 쓴다.
- **아이콘 버튼에 이름을 붙이지 않는다.** 글자가 없으면 스크린 리더는 "버튼"이라고만 읽는다. `aria-label` 같은 방법으로 이름을 주고, 뜻이 널리 알려지지 않은 아이콘이면 글자를 함께 보여 준다.
- **위험 버튼을 기본 버튼 자리에 둔다.** Enter 한 번이나 습관적인 클릭으로 실행될 수 있다. 다른 버튼과 떨어뜨려 두고, 되돌릴 수 없으면 실행 전에 한 번 확인을 받는다. 색만으로 구분하지 않도록 글자도 "확인"이 아니라 "삭제"처럼 동작 그대로 적는다.
- **누를 수 있는 영역이 보이는 크기만큼만 있다.** 아이콘 버튼과 텍스트 버튼은 보이는 부분이 작아 손가락으로 누르기 어렵다. 애플은 44pt, 머티리얼은 48dp 이상을 권하고, WCAG 2.2는 AA 수준에서 최소 24×24 CSS 픽셀을 요구한다. 보이는 크기는 작게 두더라도 눌리는 영역은 넓힌다.

## 정리

- 먼저 동작인지 이동인지 가른다. 이동이면 링크이고, 동작이면 버튼이다.
- 버튼은 위계로 나눈다. 가장 중요한 동작 하나만 주 버튼으로 두고 나머지는 그보다 덜 띄는 모양으로 내린다.
- 되돌리기 어려운 동작은 위계와 별개로 따로 구분해서 그린다.

> 버튼의 모양을 고르는 일은 그 화면에서 무엇을 먼저 누르게 할지 순서를 정하는 일이다.
